# 跨镜头一致性总检表（Consistency Checklist）

本文件是交付前的三道关。建库期（一次性资产）→ 每镜期（复用检查）→ 成片期（跨镜 A/B 比对）。任何一关不通过，退回对应阶段修复，不得带病出片。

---

## 第一关 · 建库期（开拍前一次性）

### 角色
- [ ] 角色档案填写完整（外貌 / 服装 / 配色 / 禁止改动标志元素）
- [ ] 锚点图已产（标准表情、平光、无遮挡、正面半身）并验收锁定
- [ ] 固定描述段（signature block）已浓缩，措辞顺序定稿
- [ ] 表情基线卡已填（默认 I / 常态眉眼 / 习惯微表情 / 峰值 I）
- [ ] 「已验收产物登记」表已建，锚点图路径已登记

### 场景
- [ ] 每个主场景定死描述齐全（空间结构 / 光源方向 / 主色调 / 标志性道具）
- [ ] 每个场景空景参考图已产
- [ ] 每个场景易穿帮点已列
- [ ] 场景资产登记表已建，空景图路径已登记

### 道具
- [ ] 关键道具清单已建（材质 / 尺寸 / 颜色 / 位置 / 朝向 / 破损 / 数量 / 绑定角色）
- [ ] 成对道具单独标注
- [ ] 道具参考图已产并登记

---

## 第二关 · 每镜期（写每一镜提示词时）

- [ ] 角色固定描述段原样套入（顺序措辞未动）
- [ ] 锚点图 / 上一镜尾帧已垫入（L2 / L3）
- [ ] 本次**只改一个维度**（表情 OR 姿势 OR 机位 OR 光影），其余锁死
- [ ] 表情变化走 onset/apex/offset，跨镜头差 >3 已插过渡（→ facial-expression）
- [ ] 场景空景参考图已垫入，光向未反向
- [ ] 道具位置 / 接触关系与上镜一致，无凭空生灭
- [ ] 已配 negative prompt（脸 / 场景 / 道具对应项）
- [ ] 新产图已回填对应资产登记表

---

## 第三关 · 成片期（跨镜 A/B 比对）

把相邻镜头并排比对，逐列过：

### 脸不变
- [ ] 脸型 / 发型 / 服装与锚点图一致
- [ ] 标志元素（耳环 / 挑染 / 袖标）在任意角度都在
- [ ] 表情连续，无瞬变、无橡皮脸、无假笑（只动嘴）
- [ ] 无斗鸡眼 / 左右不对称

### 景不变
- [ ] 空间结构（窗门位置 / 主色调 / 标志道具位置）一致
- [ ] 光源方向一致（未反向）
- [ ] 时间流逝时光影连续渐变，非跳变

### 道具不变
- [ ] 材质 / 颜色 / 尺寸一致（未变色变大）
- [ ] 位置 / 朝向 / 接触关系一致
- [ ] 成对道具左右都在
- [ ] 无凭空出现 / 消失

## 引擎适配速查（写提示词前看）

| 引擎 | 一致性最强手段 | 写法注意 |
|---|---|---|
| 即梦 / Seedance | **首尾帧接力（L3）**最稳；自带转场护栏（禁止瞬变 / 凭空出现），与本库规则同向 | 中文提示词；锚点图作首帧 / 角色参考 |
| 可灵 / Kling | 参考图 + 图生图 + 独立 `negativePrompt` 字段 | 约束进 negativePrompt；首尾帧 / 参考图接力 |
| 豆包 / Seedream | 以图像为主，先出参考图组再垫图生视频 | 角色参考图组（→ ip-character-studio）+ 本库清单 |
| Grok 视频 | 对英文短句敏感，长句易丢约束 | 关键约束前置；复杂编码拆短句；首尾帧接力 |

---

## 标准 negative prompt 模板（可灵 / 即梦可直接用）

```
橡皮脸, 表情瞬变, 左右脸不对称, 斗鸡眼, 眼睛失焦, 假笑(只动嘴不动眼),
脸型改变, 发型改变, 服装改变, 标志配饰丢失,
场景结构改变, 光源方向反转, 主色调改变,
道具位置跳变, 道具凭空出现或消失, 道具材质变色
```

> 用法：脸 / 景 / 道具三类分别可裁剪。纯文生图（无锚点图）时 negative 效果有限——**必须以 L2 / L3 参考图为主力，negative 仅兜底**。
