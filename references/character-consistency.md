# 角色跨镜头一致性（Character Consistency）

本文件解决"换机位就变脸"。底层资产复用两块：角色档案与锚点图技法来自 `shiyi-agi-ip-character-studio`（character-profile.md / seedance-apply.md），面部表情编码来自 `shiyiagi-facial-expression`（expression-coding.md）。本文件把它们**串成跨镜头脸一致的最小可行流程**，并补上上游没有的"角度维度取舍表"。

---

## 一、角色一致性的三种根因与对策

| 根因 | 现象 | 对策 |
|---|---|---|
| 档案模糊 | 只写"帅气男性"，模型每镜自由发挥 | 定死外貌 / 服装 / 配色 / 标志元素（写具体特征，不用不可生成词） |
| 无锚点图 | 纯文生图跨次必漂 | 先出锚点图并垫图生图，不纯文生图 |
| 一次改太多 | 脸、表情、姿势同镜全改 → 崩 | 一次只改一个维度（见总流程第四节一致性预算） |

---

## 二、最小可行流程（照做即可）

1. **填角色档案**（→ ip-character-studio character-profile.md）
   - 外貌：脸型 / 五官 / 发型发色 / 肤色 / 体型 / 年龄感（具体、可比对）。
   - 服装：上装 / 下装 / 鞋履 / **标志性配饰（必须保留）**。
   - 配色：主色 / 辅色 / 点缀色 / **禁忌配色**。
   - **禁止改动的标志元素**：左耳星形耳环、额前挑染、制服袖标等——列死，出图不得丢。
2. **产锚点图**（→ ip-character-studio seedance-apply.md）
   - 标准表情、平光、无遮挡、正面半身；挑最稳一张请用户验收锁定。
   - 锚点图是后续所有扩展（头像 / 半身 / 全身 / 姿势 / 表情 / 场景）的参考基准。
3. **浓缩固定描述段（signature block）**
   - 把档案浓缩成一段固定文字，附在每个提示词里，**顺序、措辞、关键修饰词都不动，只追加差异项**。
   - 例："林夏，28 岁女性，圆脸大眼，深棕短发带左额挑染，藏青制服配金色袖标，左耳星形耳环，主色藏青、辅色暖金、点缀青绿，扁平插画风。"
4. **填表情基线卡**（→ facial-expression 第四节）
   - 每角色一张：默认 I 值 / 常态眉眼 / 习惯微表情 / 本场戏峰值 I / 不可出现的表情。
5. **每镜复用**
   - 套固定描述段 + 垫锚点图（或上一镜尾帧，见总流程第三节）+ 只写本次要变的维度（表情 / 姿势）。
   - 表情变化走 onset/apex/offset，跨镜头差 >3 档插过渡镜（→ facial-expression 第五/十节）。

> 纪律：每产一张可用图，回填角色档案「已验收产物登记」表（锚点图 / 头像 / 半身 / 全身 / 姿势集 / 表情集 / 场景），标注路径。没有回填 = 不可追溯 = 下集必乱。

## 三、不同镜头角度下"必须写死 vs 可放松"

锚点图管正面，但镜头会绕到侧面 / 背面 / 远景。哪些特征不能丢：

| 镜头 | 必须写死（不变） | 可放松（随角度变） |
|---|---|---|
| 正面特写 | 脸型、五官比例、标志配饰、发型 | 表情（本次主改） |
| 侧面 | 鼻梁线条、下颌线、发型轮廓、耳环 | 双眼对称（侧脸只露一只） |
| 背面 | 发型、服装后背细节、身高体态 | 面部（不露） |
| 远景 / 全景 | 服装主色、体型、标志配饰轮廓 | 五官细节（看不清） |
| 换妆 / 换装镜 | 脸型与发型（除非剧情要求） | 服装可换（但需在档案注明） |

**红线：** 标志元素（耳环 / 挑染 / 袖标）在任何角度都不得丢失；一旦丢失即判定该镜不合格。

---

## 四、锚点图怎么来（复用 seedance-apply.md 要点）

- 有参考图：用信息最全的一张直接作锚点，或先统一重绘一张标准锚点。
- 从零：文生图出 2–3 张候选，挑最稳一张验收锁定。
- 图生图 / 垫图：每次扩展都**上传锚点图（或上一张已验收图）作参考**，而非纯文生图。
- 避坑：不要在同一张图上反复堆形容词"修正"；未通过就作为新请求重出。配色用具体色值 / 色名，避免"蓝色系"。

---

## 五、与表情编码的协同（→ facial-expression 第六/十节）

- 锚点图负责"脸不变"，表情编码负责"表情怎么变"——二者分工：**换表情不变脸**。
- 跨镜头表情一致：每个表情镜以锚点图作参考输入，只改表情编码段，不改脸型 / 发型 / 服装描述。
- 合格判定（facial-expression 第十节 8 项）全部满足才算过关；一处不满足退回修改。

---

## 六、角色一致性自检（每镜 / 每集）

- ✅ 固定描述段是否原样套入（顺序措辞未动）？
- ✅ 锚点图 / 上一镜尾帧是否垫入？
- ✅ 标志元素（耳环 / 挑染 / 袖标）在任意角度都还在？
- ✅ 表情变化走基线卡，跨镜头差 >3 已插过渡，无瞬变？
- ✅ 本次只改了一个维度，其余锁死？
- ✅ 新产图已回填「已验收产物登记」？
