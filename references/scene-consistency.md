# 场景跨镜头一致性（Scene Consistency）

本文件解决"每集场景都不一样、窗外白天变夜晚、道具位置乱跳"。底层资产复用豆包「06 场景资产」指令（定死描述 = 空间结构 / 光源方向 / 主色调 / 标志性道具；空景参考图；易穿帮点）。本文件补上上游没有的：**空间一致性 + 光影时序一致性双层面**，以及"换机位时场景身份不丢"的规则。

---

## 一、场景一致性的两个层面（都得过）

观众察觉场景穿帮有两条路径，必须分别锁：

1. **空间结构不变**：同一场景的房间布局、窗 / 门 / 柱子的位置、主色调、标志性道具的位置——换机位也不能变。
2. **光影时序不变**：同一场戏内如果是"同一时刻"，光向、光色、明暗不能每镜跳；如果是"时间流逝"，光影要**连续变化**而非跳变（不能第一镜白天、第三镜夜晚，除非剧情明确转场）。

> 最易被察觉的穿帮 = 光源方向不写死，每集光影都变。这是头号红线。

---

## 二、建场景资产（复用豆包「06 场景资产」）

每个主场景（3–5 个）走三步：

1. **写定死描述**（四要素，缺一不可）：
   - 空间结构：房间大小、布局、窗门位置、固定家具。
   - **光源方向**：自然光从左上打入 / 顶光 / 窗在人物左侧——写死方向。
   - 主色调：墙色、地面、整体影调（具体色名 / 色值）。
   - 标志性道具：桌上旧显示器、门口绿植等"场景身份证"。
2. **出空景参考图**：纯场景、无人、平光或定死光向，作为后续带角色镜的垫图基准。
3. **列易穿帮点**：窗的位置与光向 / 道具位置 / 主色调 / 某件标志性家具。

> 规格示例：老办公室 / 十平米，窗在人物左侧，自然光从左上打入，米黄墙，桌上有台旧显示器 / scene_office.png / 易穿帮：窗的位置与光向。

**边界：** 缺失描述不得留空，标【待定】；不同场景不得混用同一张参考图；未成功生成的标【生成失败】，不得拿近似场景充数。

---

## 三、换机位时场景身份不丢

同一个场景从不同机位拍，观众仍能认出"是这间屋子"。规则：

- 每镜都垫**同一张空景参考图**（或用上一镜尾帧接力，见总流程第三节）。
- 空间结构描述段（窗门位置 / 主色调 / 标志道具）写进固定描述段，原样复用。
- **光向是绝对红线**：所有同场景同时刻镜头，光源方向必须一致；侧光从哪边来就永远从哪边来。
- 机位变了，场景的"身份标志"（窗位置、主色、标志性道具）必须一致，只有构图 / 景别变。

---

## 四、光影时序连续性

- 同场戏"同一时刻"：光向 / 光色 / 明暗锁定，禁止每镜微调方向。
- "时间流逝"（日→夜 / 晨→午）：光影**连续渐变**，用 onset/apex/offset 思路（参考 facial-expression 第七节）让光线平滑过渡，不瞬跳。
- 顶光 / 侧光 / 底光（鬼光）/ 柔光的选择一旦定下，同场景情绪基调不变（除非剧情转折明确改光）。

---

## 五、双轨参考图

- **空景参考图**：纯场景，用于锁空间结构 + 光向，垫在带角色镜里保证"景不变"。
- **带角色参考图**：已验收的某镜成片，用于接力（L3）或作为后续相似镜的 L2 参考。

两轨都进场景资产登记，标注路径与用途。

---

## 六、场景一致性自检（每镜 / 每集）

- ✅ 空景参考图是否垫入 / 上一镜尾帧是否接力？
- ✅ 空间结构（窗门位置 / 主色调 / 标志道具）与资产一致？
- ✅ 光源方向是否和资产一致（未反向）？
- ✅ 若是时间流逝，光影是否连续渐变而非跳变？
- ✅ 易穿帮点（窗 / 光向 / 道具位置）是否守住？
- ✅ 新产空景 / 带角色场景图已登记？
