# 道具跨镜头一致性（Prop Consistency）

本文件解决"道具位置乱跳、凭空出现 / 消失、材质变色"。相比角色与场景，道具一致性最常被忽略，却是观众潜意识里最挑刺的一环——**道具是第三主角**。本文件是全新内容，上游无直接对应资产。

---

## 一、道具为什么会穿帮

| 根因 | 现象 | 对策 |
|---|---|---|
| 没登记 | 道具每次现编，位置 / 颜色随缘 | 建道具清单，定死六要素 |
| 接触关系乱 | 这镜左手拿、下镜右手拿、再下镜桌上 | 锁"谁拿、怎么拿、放哪" |
| 凭空生灭 | 关键道具前一镜没有、后一镜出现 | 锁出场 / 消失的连续性 |
| 成对道具崩 | 眼镜只画一只腿、耳机只一边 | 成对道具单独标注 |

## 三、接触关系一致性（最易漂的隐性维度）

道具不是孤立的，它和"手 / 身体 / 场景"有接触关系，这条关系必须锁：

- **谁拿着**：固定左手 / 右手 / 双手 / 无人（在桌上）。
- **怎么拿**：握把 / 托底 / 夹腋下 / 挂肩——动作一致。
- **放哪**：桌面左后 / 兜里 / 地上右脚边——位置一致。
- **成对道具**：眼镜两条腿、耳机两边、耳环一对——左右都在，形态一致。

> 规则：换镜时若道具仍在使用中，接触关系（谁拿、怎么拿、放哪）必须和上镜一致；若要改变，必须在分镜表明确写出"交接动作"，而非让模型自行决定。

---

## 四、出场 / 消失的连续性（禁止凭空生灭）

- 道具首次出现必须有"入场"：角色取出 / 画面中原本就在 / 明确转场。
- 道具消失必须有"离场"：放下 / 收起 / 转场切走。
- **禁止**：前一镜不存在、后一镜突然在手里；或前一镜在桌上、后一镜凭空没了——除非剧情明确"用了 / 丢了"。
- 长序列用总流程第三节 L3 接力：上一镜尾帧里道具的位置，直接约束下一镜。

---

## 五、道具与角色绑定

- 标志道具（林夏的金丝眼镜、左耳星形耳环）记入角色档案「禁止改动的标志元素」，与角色一致性同红线。
- 道具参考图并入角色 / 场景资产登记，避免散落丢失。

---

## 六、道具一致性自检（每镜 / 每集）

- ✅ 道具材质 / 颜色 / 尺寸与清单一致（未变色变大）？
- ✅ 位置 / 朝向与上一镜一致，或无明确交接动作？
- ✅ 接触关系（谁拿 / 怎么拿 / 放哪）一致？
- ✅ 成对道具左右都在、形态一致？
- ✅ 无凭空出现 / 消失（有入场 / 离场或转场）？
- ✅ 绑定角色的标志道具与角色档案一致？
- ✅ 新产道具参考图已登记？
