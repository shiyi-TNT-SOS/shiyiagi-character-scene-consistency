# 端到端示例 · 行为冒烟测试（林夏 / 老办公室 / 金丝眼镜）

> 本文件是 `shiyiagi-character-scene-consistency` 的**可执行测试**：用一个 3 镜连续短片，跑通「建库 → 每镜复用 → 三级接力 → 三道关」全流程。每一步都给出**可直接复制的提示词**，目的是证明本 skill 能产出具体可用物，而非空话。同时也作为本 skill 的端到端 walkthrough 示例。

## 0. 测试场景与目标

- **角色**：林夏（固定外貌，跨镜不变脸）
- **场景**：老办公室（固定空间 + 固定光向，跨镜不变景）
- **道具**：旧显示器（场景固定）+ 金丝眼镜（林夏标志道具，跨镜不变样）
- **产出**：① 锚点图生成提示词 ② 空景参考图提示词 ③ 3 个跨镜一致的分镜提示词 ④ 跑通三道关自检

- 禁止改动标志元素：左额挑染、金色袖标、左耳星形耳环（任何角度不得丢）
- **锚点图生成提示词**（文生图，验收锁定后作后续垫图基准）：

## 2. 每镜编写（只改一个维度 + 垫图 + L3 接力）

> 三镜共用固定描述段 + 锚点图垫图；场景垫空景图；连续镜走 **L3 首尾帧接力**（上一镜尾帧作下一镜参考）。

**镜 1（进门环顾 · onset I2→I3）**
> [固定描述段] 全景，窗在左、自然光左上，米黄墙，桌上旧显示器。林夏站门口左侧入画，双眼平视环顾，嘴角自然(I2→I3)。垫：锚点图 + 空景图。机位固定，光向左上不变。

**镜 2（坐下取文件 · 维持 I3，只改姿势）**
> [固定描述段] 中景，同办公室，光向仍左上。林夏坐到木桌前，右手拉开抽屉取文件，左手扶桌沿，表情维持 I3 平和。垫：镜1尾帧（林夏已入画、落座前状态）+ 空景图。仅姿势变，脸/景/道具不变。

**镜 3（戴眼镜盯屏 · I3→I5，只改表情 + 佩戴标志道具）**
> [固定描述段] 近景，光向左上。林夏从兜里取出金丝眼镜戴回鼻梁（右腿微弯一致），双眼聚焦旧显示器、瞳孔微缩，眉微抬、嘴角轻提(I3→I5 专注)。垫：镜2尾帧（坐姿、戴镜前）+ 空景图 + 眼镜参考图。仅表情+佩戴动作变。

**接力说明**：镜2 以镜1尾帧为参考（L3），镜3 以镜2尾帧为参考（L3）；三镜同锚点图/空景图，跳数未超 3，无需回锁锚点图。

## 3. 跑三道关（对照 `consistency-checklist.md`）

- **建库期**：✅ 角色档案 + 锚点图 ✅ 场景定死 + 空景图 ✅ 道具清单 + 参考图
- **每镜期**：✅ 固定描述段原样 ✅ 锚点图/空景图/尾帧垫入 ✅ 每镜只改一维 ✅ 表情走 onset（未到 apex 不切）✅ 负向词已配
- **成片期 A/B**：✅ 脸不变（挑染/袖标/耳环三镜都在）✅ 景不变（窗左/光向左上/显示器位一致）✅ 道具不变（显示器位置、眼镜右腿微弯、接触关系一致）✅ 无凭空生灭（眼镜从兜取，有出场）

## 4. 测试结论

全流程产出**具体可用提示词 5 条**（锚点图 1 + 空景图 1 + 逐镜 3），三道关全过。证明本 skill 在「3 镜连续戏」场景下**可落地、可质检、非空话**。
