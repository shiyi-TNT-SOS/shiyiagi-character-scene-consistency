# 跨镜头一致性 · 开工速查卡（Quickstart）

> 一页纸。赶时间只看这张：开工前建库、每镜只改一个维度、连续镜走首尾帧接力、三道关过关再拼。完整方法见 `consistency-workflow.md`。

## 0. 先判断要不要上这套

- 单图 / 单镜、无连续性 → **不用**，直接出。
- 多镜 / 多集 / 有固定角色或场景 → **必上**，否则必漂（换机位变脸、每集场景不一样、道具乱跳）。

## 1. 建库三件套（开工前做，最贵也最省）

| 资产 | 去哪建 | 产出 | 必带 |
|---|---|---|---|
| 角色 | `shiyi-agi-ip-character-studio` | 角色档案 + 锚点图 | 固定描述段(signature block) + 表情基线卡(`shiyiagi-facial-expression`) |
| 场景 | 本库 `scene-consistency.md` + 豆包「06 场景资产」 | 定死描述 + 空景参考图 | 光源方向 + 易穿帮点 |
| 道具 | 本库 `prop-consistency.md` | 道具清单 + 道具参考图 | 六要素 + 接触关系 |

> 每产一张可用参考图，立刻回填对应档案的「已验收产物登记」表，标路径。没回填 = 不可追溯 = 下集必乱。

## 2. 每镜写法（复用期）

- 套固定描述段（**原样**，不改顺序措辞）。
- 垫锚点图 / 空景图 / 上一镜尾帧。
- **只改一个维度**（表情 OR 姿势 OR 机位 OR 光影），其余锁死。
- 表情走 onset/apex/offset（→ `shiyiagi-facial-expression`）；跨镜头差 >3 档插过渡镜。
- 套 negative prompt（→ `consistency-checklist.md` 标准模板）。

## 3. 接力锁死（生成期，最强手段）

- 连续镜头：上一镜**尾帧**作下一镜首帧 / 参考（L3 首尾帧接力）。
- 每 **3 跳**回锁一次锚点图 / 空景图；**跨场景不接力**。
- 口诀：**文字串保底、参考图稳压、首尾帧锁死。**

## 4. 三道关（质检期，不过不拼）

- **建库期**：三件套齐全 + 各带参考图？
- **每镜期**：只改一维？垫图？负向词？
- **成片期**：脸 / 景 / 道具 A/B 比对（→ `consistency-checklist.md`）。

## 5. 引擎一句话

| 引擎 | 一致性最强手段 |
|---|---|
| 即梦 / Seedance | 首尾帧接力（L3）最稳 |
| 可灵 / Kling | 参考图 + 图生图 + 独立 negativePrompt |
| 豆包 / Seedream | 先出参考图组再垫图生视频 |
| Grok | 英文短句前置，复杂编码拆短句 |

---

**红线三不变**：脸不变（标志元素任何角度不得丢）/ 景不变（光源方向不反向）/ 道具不变（不凭空出现消失）。任一漂移即退回重出。
