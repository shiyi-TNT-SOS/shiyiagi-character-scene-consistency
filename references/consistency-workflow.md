# 跨镜头一致性总流程（Character / Scene Consistency Workflow）

本文件是「角色/场景一致性库」的总入口。它解决一类反复出现的翻车：**换机位就变脸、每集场景都不一样、道具位置乱跳**。根因只有三类——①档案模糊（没有定死的视觉描述）、②没有锚点图（纯文生图跨次必漂）、③一次改太多维度（脸、表情、姿势、机位、光影同时变，模型顾不过来）。

本 skill 不重复造轮子：角色建库复用 `shiyi-agi-ip-character-studio`，面部表情编码复用 `shiyiagi-facial-expression`，场景资产复用豆包「06 场景资产」指令。本文件负责把它们**编排成一条可复用的跨镜头一致性流水线**，并给出上游没有的「三级接力法 / 一致性预算 / 三不变清单」。

---

## 一、核心判断

> **一致性不是靠形容词堆出来的，是靠"可复用的资产 + 一次只改一个维度 + 接力锁死"锁出来的。**

- 角色的脸、场景的景、道具的样，必须在**开拍前**就有"基准资产"（档案 + 参考图），而不是每镜现编。
- 每一镜只改你**这次要表达**的那一个维度，其余全部套用固定描述段（signature block）/ 垫入锚点图。
- 跨镜头用「三级接力」把上一镜的成果传给下一镜，避免纯文字描述自己飘走。

---

## 二、总流程（四阶段）

### 阶段 0 · 建库（一次性，最贵也最省）
为整部片建三件套，**每样都带参考图**：

1. **角色档案 + 锚点图**（→ `shiyi-agi-ip-character-studio` 的 character-profile.md + seedance-apply.md）
   - 填角色档案：外貌 / 服装 / 配色 / 禁止改动标志元素。
   - 产锚点图：标准表情、平光、无遮挡、正面半身，请用户验收锁定。
   - 浓缩出**固定描述段（signature block）**：顺序措辞不变，附在每个提示词里。
   - 填表情基线卡（→ `shiyiagi-facial-expression` 第四节）。
2. **场景资产 + 空景参考图**（→ 豆包「06 场景资产」指令 + 本库 scene-consistency.md）
   - 每个主场景写定死描述（空间结构 / 光源方向 / 主色调 / 标志性道具）。
   - 各出一张空景参考图。
   - 列出每个场景"最容易穿帮的点"。
3. **道具清单 + 道具参考图**（→ 本库 prop-consistency.md）
   - 列关键道具，定死材质 / 尺寸 / 颜色 / 位置 / 朝向 / 破损状态 / 数量。
   - 成对道具（眼镜、耳机）与角色绑定道具单独标注。

> 建库纪律：每产一张可用图，立刻回填到对应档案的「已验收产物登记」表，标注路径与 SHA256。验收锁定后跑 `scripts/asset_hash.py init <资产目录>` 登记指纹清单（详见 [asset-hash.md](asset-hash.md)）。没有回填的图等于没产。

### 阶段 1 · 每镜编写（复用期）
写每一镜提示词时：
1. 套入角色固定描述段（原样，不改顺序措辞）。
2. 垫入锚点图 / 上一镜尾帧（见第三节接力法）。**垫图前先跑 `scripts/asset_hash.py check <资产目录>`，确认参考图无 CHANGED/MISSING 再垫。**
3. 只写**本次要变的那一个维度**（姿势 OR 表情 OR 机位 OR 光影），其余沿用档案。
4. 套对应 negative prompt（脸→facial-expression 第五节；场景/道具→本库 checklist）。
5. 视频按 facial-expression 第七/十节做 onset/apex/offset 动态。

### 阶段 2 · 接力（锁死期，见第三节）
上一镜成片后，取其尾帧作下一镜的参考输入，保持链不漂；每 3 跳回锁一次锚点图。

### 阶段 3 · 质检（兜底期，见 consistency-checklist.md）
建库期 / 每镜期 / 成片期三道关逐镜过关。

## 三、三级一致性接力法（本库核心增量）

不同"锁一致性"手段的可靠性天差地别。按可靠性从低到高：

| 级别 | 手段 | 可靠性 | 适用 | 漂移风险 |
|---|---|---|---|---|
| **L1 文字串** | 固定描述段（signature block）原样复用 | 最低 | 同一次会话内 / 同镜头内 | 高（模型每镜自由发挥） |
| **L2 参考图** | 锚点图 / 空景图 / 道具图垫图（图生图） | 中高 | 跨镜头、换机位、换角度 | 中（依赖垫图质量） |
| **L3 首尾帧接力** | 上一镜**尾帧**作下一镜**首帧/参考** | 最高 | 连续动作、镜头相接、长序列 | 低（直接继承像素） |

**接力规则（铁律）：**
- 连续镜头用 **L3**：把上一镜尾帧直接作为下一镜的输入参考（即梦/Seedance 的首尾帧、可灵的首尾帧 / 参考图）。
- 跨场景 / 时空跳跃**不接力** L3（没有视觉连续性可言），改用 L2（各自锚点图）。
- 一条 L3 接力链**最多 4–5 跳**；每 **3 跳**必须回锁一次锚点图 / 空景图，防止误差累积漂移。
- L1 文字串永远要写，但**不能单独依赖**——它是"最低保障"不是"主力"。

> 口诀：**文字串保底、参考图稳压、首尾帧锁死；跨场景不接力、每三跳回锚。**

**表情接力特别说明**：表情是连续渐变的，渐变序列（如悲伤 I3→I5→I7）优先用 **L3 首尾帧接力**锁定表情连续——上一镜尾帧的表情直接继承到下一镜首帧，比只垫锚点图（L2）锁死力度更强；跨场景、或跨度大跳变（差 >3 档）时回锁 L2 锚点图重定基线（详见 facial-expression 第六/十节）。

## 四、一致性预算（本库核心增量）

一场戏里模型能稳定控制的变量有限。**一次只改一个维度**，其余全部锁死：

| 维度 | 锁死方式 | 本次可改吗 |
|---|---|---|
| 脸型 / 发型 / 服装 | 固定描述段 + 锚点图 | ❌ 不可改 |
| 表情 | 表情基线卡 + onset/apex/offset | ✅ 本次主改 |
| 姿势 / 走位 | 档案姿势集 | ✅ 本次主改 |
| 机位 / 景别 | 分镜表 | ✅（但场景身份标志不能变） |
| 光影 / 时段 | 场景资产定死光向 | ⚠️ 可微调，方向不能反 |
| 道具 | 道具清单定死 | ❌ 不可变样 |

**规则：** 若同一镜既要换表情又要换姿势又要换机位，拆成多镜分别生成再剪辑，不要在一镜里全改。一次改多个维度 = 必漂。

## 五、三不变清单（逐镜自检红线）

每一镜交付前，对着三条红线过一遍：

1. **脸不变**：脸型 / 发型 / 服装 / 标志配饰与锚点图一致；表情变化走基线卡与过渡，无瞬变。
2. **景不变**：空间结构、窗/门位置、主色调、标志性道具位置与空景参考图一致；光向不反向。
3. **道具不变**：材质 / 颜色 / 位置 / 朝向 / 数量与道具清单一致；不凭空出现 / 消失；拿法不变。

任一红线疑似漂移 → 退回，按第三节接力法补参考图 / 回锁锚点图重出。
