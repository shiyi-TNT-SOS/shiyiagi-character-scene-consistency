# 资产哈希登记与比对（防参考图被偷换 / 损坏）

> 本文件是「角色/场景/道具一致性库」的**安全锁**：给锚点图、空景图、道具图登记 sha256 指纹，垫图前自动比对，防止参考图被偷偷替换、损坏或丢失。

## 为什么需要它

一致性库的命根子是**参考图**——锚点图锁脸、空景图锁景、道具图锁道具。一旦这些图被：

- **误替换**（同文件名换了张别的图）
- **损坏**（传输/编辑中途截断）
- **删除/移动**（路径变了，垫图落空）

整批出图就会静默漂移，而人眼极难在成百张图里发现"这张其实是另一张"。哈希指纹（见「哈希」概念）正好治这个：**同样的图永远同一个指纹；图被改一个像素，指纹就天差地别**。比对指纹就知道图有没有被动过，不用肉眼看。

## 工具位置

```
shiyiagi-character-scene-consistency/scripts/asset_hash.py
```

纯 Python 3 标准库，无需安装任何包。Windows（Git Bash / PowerShell）、macOS、Linux 都能跑。

## 三步用法

### 1. 建库验收后 · 登记（init）

资产目录（放好锚点图/空景图/道具图）验收锁定后，扫一遍生成指纹清单：

```bash
python scripts/asset_hash.py init <资产目录>
```

会生成 `asset-hash-manifest.json`，记录每张图的相对路径与 sha256。日后新增图片，重跑 `init` 即可更新清单。

### 2. 每镜垫图前 · 比对（check）

写每一镜、准备垫参考图之前，跑一次比对：

```bash
python scripts/asset_hash.py check <资产目录>
```

输出四类结果：

| 标记 | 含义 | 处理 |
|---|---|---|
| `OK` | 指纹一致，图没动 | 放心垫图 |
| `CHANGED` | 内容变了（被替换/损坏） | **停手**，找回原图或重出，否则整批漂 |
| `MISSING` | 文件不见了 | 找回原图，或确认后重跑 init |
| `ADDED` | 新文件未登记 | 跑 init 更新清单 |

`CHANGED` 或 `MISSING` 存在时，脚本退出码为 `1`（便于写进批处理/自动化判断）；全一致为 `0`。

### 3. 手动填表 · 单文件指纹（file）

想手动把某个图的指纹填进资产登记表（见下方模板）时：

```bash
python scripts/asset_hash.py file <图片路径>
```

直接打印该文件 sha256，复制进表的「SHA256」列。

## 怎么融入一致性流程

| 阶段 | 动作 |
|---|---|
| 建库期（开拍前） | 资产图验收锁定 → 跑 `init` 登记指纹 → 回填资产登记表（含 SHA256 列） |
| 每镜期（写提示词时） | 垫参考图前跑 `check` → 全 `OK` 才垫图；出现 `CHANGED/MISSING` 先解决 |
| 成片期（跨镜比对时） | 若成片疑似漂移，先 `check` 排除"参考图被换"这一根因，再查别的 |

> 口诀：**建库登记指纹、垫图前必 check、CHANGED/MISSING 不过不垫。**

## 退出码（自动化用）

- `0`：check 全一致 / file 成功 / init 成功
- `1`：check 存在 CHANGED 或 MISSING（垫图前必须拦截）
- `2`：参数错误（目录/文件不存在、清单缺失）
